4.2 Coral cover by depth

Live coral cover fell from 38% at 5 m to 21% at 15 m across the northern transects (Figure 4.3). The drop was steepest at sites exposed to the prevailing swell, as reported in earlier surveys [12].

Sites sheltered by the outer reef kept higher cover at every depth; Table 4.1 lists the counts per site and the method follows Section 2.4.

What the alpha does

Fast

Documents open almost at once, and pages keep up as you scroll and zoom, even in files of hundreds of pages.

Light

A small download that installs for your user without admin rights and leaves room for everything else you have open.

SmartLinks

Figures, tables, sections and citations mentioned in the text become links. Preview what a reference points to, jump there, and see everywhere it is mentioned.

Tabs

Open several documents, or the same one at two places, and move between them easily.

Find and copy

Search the whole document, select text and copy it with its reading order kept.

Keyboard and screen reader

Every control is reachable by keyboard, and screen readers can read the controls and the page text. Dark and light themes.

System requirements

  • Windows 10 or Windows 11, 64-bit (x64), for this alpha; more platforms are planned
  • No admin rights needed

Before you install an alpha

  • It reads PDFs only: no annotations, forms or printing yet.
  • zPDF tells you when a new alpha build is out and updates itself when you restart it. The portable zip only shows the notice.
  • Expect bugs. A damaged file should show an error, never crash the app; if it crashes, please tell us.

Found a problem? Report a bug with the version number and what you did. Attach the PDF only if you are allowed to share it.

Check your download

The alpha is not code-signed yet, so Windows SmartScreen may say it “protected your PC”. Choose More info, then Run anyway. Before you do, check that the file matches the one we published:

SHA-256 is listed on the releases page.

In PowerShell, in your Downloads folder, run this and compare the result with the value above:

Get-FileHash .\zpdf-<version>-windows-x64.zip -Algorithm SHA256
